# Larevia — Website

Site institucional responsivo em HTML, CSS e JavaScript, sem dependências externas.

## Configuração antes de publicar

1. Abra `config.js`.
2. Troque `351000000000` pelo número real de WhatsApp no formato internacional.
3. Troque o e-mail de exemplo.
4. Ajuste zonas, serviços e textos conforme necessário.

## Visualização local

Abra `index.html` no navegador ou use um servidor local:

```bash
python -m http.server 8000
```

Depois aceda a `http://localhost:8000`.

## Publicação

A pasta pode ser publicada diretamente no Netlify, Vercel, GitHub Pages ou alojamento tradicional.
